# 🏗️ G3 Architects

A clean and responsive **architectural landing page** built with **HTML5 and CSS3**.
This project focuses on modern layout techniques, responsive design, reusable components, and a professional architectural website interface.

---

## 🌐 Live Preview

🔗 **Live Website:** `https://nazmulo.github.io/G3-Architect/`

---

## ✨ Features

* 🏠 Modern navigation bar with Home, About, Contact Us, and Login
* 🎨 Attractive hero/banner section
* 👥 Team members showcase
* ⚡ Quick Features section
* 📱 Desktop & mobile-focused feature cards
* 🏆 Statistics and achievement section
* 🤝 Sponsors/partner showcase
* 🖼️ Image-based architectural presentation
* 📐 Clean and organized HTML structure
* 🎯 Responsive-friendly layout
